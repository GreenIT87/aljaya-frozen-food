Cara Sinkronisasi 2-Arah Google Sheets:
1) Buka Google Sheet Anda → klik Extensions > Apps Script.
2) Klik tombol Copy Script di kiri, hapus kode lama & paste script baru.
3) Klik Deploy > New Deployment > Web App (Execute as: Me, Who has access: Anyone).
4) Salin URL Web App ke kolom di kiri, lalu klik SYNC SEKARANG (kirim data ke Sheet) atau TARIK DATA (ambil dari Sheet).
